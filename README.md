# Science Escape LIVE — Adventure UI

อัปเดตหน้าจอเกมเป็นแผนที่ผจญภัย 6 คดี โดยรักษาระบบ Socket.IO เดิมไว้

## วิธีอัปเดตเว็บเดิม
1. เปิด GitHub repository ที่ใช้งานอยู่
2. เข้า public/index.html กดไอคอนดินสอ และแทนที่เนื้อหาด้วย public/index.html ในชุดนี้ หรืออัปโหลดไฟล์แทนที่
3. Commit changes และรอ Render Auto Deploy
4. ทดสอบกับครู 1 เครื่องและมือถือ 2 เครื่องก่อนใช้จริง

## การทำงาน
- ครูควบคุมการเปิดคดีเหมือนเดิม
- แผนที่แสดงสถานะล็อก/กำลังเล่น/ผ่านด่าน โดยไม่ได้บังคับว่าต้องตอบถูกเพื่อไปต่อ
- เบาะแสช่วยคิดไม่ใช่เฉลยและไม่มีการหักคะแนน
- คะแนนยังเป็น 100 ต่อคำตอบที่ถูก สูงสุด 600 ตามระบบเดิม
- ยังไม่มีฐานข้อมูลถาวร ต้องส่งออก CSV หลังจบ
