# เกมนักสืบแยกสาร LIVE (ม.2)

เกมตอบคำถาม 6 คดี แข่งขันพร้อมกันผ่านมือถือ มีห้องครู QR Code เวลานับถอยหลัง ตารางคะแนนสด และส่งออก CSV

## ทดลองในคอมพิวเตอร์
1. ติดตั้ง Node.js 18 ขึ้นไป
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน `npm install` และ `npm start`
3. เปิด `http://localhost:3000` บนคอมพิวเตอร์
4. ถ้าจะให้มือถือเข้าร่วม ต้องเผยแพร่เป็น HTTPS ออนไลน์ก่อน (localhost ใช้ได้เฉพาะเครื่องตัวเอง)

## เผยแพร่ออนไลน์ผ่าน Render
1. อัปโหลดโฟลเดอร์โปรเจกต์นี้ขึ้น GitHub repository (ควรอัปโหลดไฟล์ `package.json`, `server.js` และโฟลเดอร์ `public` ที่ระดับบนสุด)
2. เข้า https://dashboard.render.com/ เลือก New > Web Service แล้วเชื่อม repository
3. Runtime: Node, Build Command: `npm install`, Start Command: `npm start`
4. เลือกแผนที่รองรับการใช้งานของคุณ (แผน/ราคาเปลี่ยนแปลงได้) แล้ว Deploy
5. เปิด URL HTTPS ที่ Render ให้มา ครูสร้างห้อง นักเรียนสแกน QR หรือเข้าลิงก์
6. ครูเปิดทีละคดี นักเรียนตอบภายในเวลา ครูดูคะแนนและส่งออก CSV หลังจบเกม

## ข้อจำกัดสำคัญ
- ข้อมูลห้องและคะแนนเก็บในหน่วยความจำเซิร์ฟเวอร์เท่านั้น รีสตาร์ต/พักเครื่อง/เปลี่ยน instance แล้วข้อมูลจะหาย
- ใช้เซิร์ฟเวอร์เพียง 1 instance เพราะยังไม่มีฐานข้อมูลหรือระบบแชร์สถานะข้าม instance
- ครูควรดาวน์โหลด CSV ก่อนปิดห้องหรือเซิร์ฟเวอร์
- QR Code ใช้บริการภายนอก `api.qrserver.com`; ถ้าบริการนั้นไม่พร้อม ให้ส่งลิงก์เข้าห้องแทน
- รหัสครูเก็บใน sessionStorage ของแท็บนั้น ไม่ควรแชร์หน้าจอ URL ที่มีข้อมูลลับ (ลิงก์นักเรียนไม่มีรหัสครู)
- นักเรียนใช้ชื่อและเลขที่เพื่อระบุผลคะแนน ไม่ใช่ระบบยืนยันตัวตน จึงควรตรวจสอบชื่อกับรายชื่อจริง
- การเก็บข้อมูลนักเรียนควรแจ้งวัตถุประสงค์และปฏิบัติตามนโยบายคุ้มครองข้อมูลของโรงเรียน
- คะแนน 100 ต่อคำตอบถูก 1 ข้อ สูงสุด 600 คะแนน ไม่หักคะแนนเมื่อตอบผิดหรือหมดเวลา
- เฉลยแสดงเฉพาะหน้าครูหลังปิดรับคำตอบ ไม่แสดงบนมือถือของนักเรียน
